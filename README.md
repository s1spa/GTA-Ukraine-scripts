# GTA Ukraine Scripts (ScriptedWpf)

GTA Ukraine Scripts — це десктопний застосунок на WPF (.NET / C#), розроблений для автоматизації рутинних задач, міні-ігор та механік у грі GTA Ukraine. 

Проєкт побудований на модульній архітектурі, де кожен скрипт/автоматизація є окремим модулем (Cog).

---

## Технологічний стек

- Платформа / Мова: .NET / C#
- UI Фреймворк: WPF (Windows Presentation Foundation)
- Низькорівнева взаємодія: Windows API (user32.dll, kernel32.dll) для кліків, симуляції клавіш, перехоплення гарячих клавіш (Global Hotkeys) та оверлеїв.
- Архітектура: Модульна система динамічного завантаження плагінів (Core/ModuleLoader.cs, IModule).

---

## Модулі (Cogs)

Усі модулі розташовані в директорії ScriptedWpf/Cogs/ та мають власні конфігураційні файли JSON.

### 1. Wires (cogs/wires)
- Опис: Автоматизація міні-гри з проводами (електрика/злам).
- Логіка: Аналізує схему або кольори проводів та проводить лінії/з'єднання у грі.

### 2. Himlab / Хімлабораторія (cogs/himlab)
- Опис: Скрипт для міні-гри хімічної лабораторії / варильні.
- Логіка: Виконання послідовності дій для варильного процесу за визначеними таймінгами та алгоритмом.

### 3. Hlorka / Хлорка (cogs/hlorka)
- Опис: Автоматичне збирання/обробка хлорки або подібних ігрових ресурсів.
- Логіка: Використовує візуальний оверлей (HlorkaOverlay.cs) та алгоритм відстеження об'єктів для точного виконання міні-гри.

### 4. Trigger / Тригер-бот (cogs/trigger)
- Опис: Автоматичне спрацьовування дій при зміні пікселів або появі елементів у визначеній зоні екрана.
- Особливості:
  - SelectionOverlayWindow.cs: Виділення зони тригера на екрані.
  - KeyCaptureUi.cs: Налаштування гарячих клавіш активації/деактивації.

### 5. Anti-AFK (cogs/antiafk)
- Опис: Модуль для запобігання кіку за неактивність (AFK).
- Логіка: Періодично симулює мікро-рухи або натискання клавіш, щоб персонаж залишався в системі активним.

### 6. CDA / Оповіщення та нотифікації (cogs/cda )
- Опис: Система сповіщень про ігрові події з аудіо-супроводом.
- Містить: Набір вбудованих звуків (notification_1.mp3, notification_2.mp3, notification_3.mp3).
